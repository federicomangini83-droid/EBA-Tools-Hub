EBA Tools Hub

A single workspace for EBA, regulatory reporting and data management tools.

Tool catalogue

The hub hosts independent browser-based tools within one repository and one GitHub Pages deployment.

FDAvailable

Flat Data Model Creator

Transforms a standard Excel workbook into a flat CSV data model, with GitHub storage, download and deletion.

  • Local Python processing in the browser
  • Versioned CSV storage
  • Raw file access for external software
CMAvailable

EBA CSV Merger

Merges multiple EBA CSV files and enriches the result with coordinates from the reporting framework workbook.

  • Fully browser-based Pyodide processing
  • Robust encoding and separator detection
  • Versioned CSV storage
DPMAvailable

DPM 2.0 Taxonomy Extractor

Extracts DPM 2.0 taxonomy tables from EBA JSON files and builds a consolidated Excel workbook.

  • Recursive taxonomy folder scan
  • Exclude list and specific list filters
  • Workbook storage and versioning
